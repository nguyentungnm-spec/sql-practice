# SQL Practice

> A personal SQL learning repository focused on database fundamentals, query optimization, and real-world business problems.

## About

This repository documents my journey learning SQL using PostgreSQL.

Instead of only collecting SQL solutions, I focus on understanding:

- Database design

- SQL query writing

- Query optimization

- Execution plans

- Transactions

- Real business scenarios


The goal is to build a solid SQL foundation for Backend Development and Information Systems.
