# 09 — Index

## Objective

Learn how indexes improve query performance and how to analyze query execution in PostgreSQL.

## Prerequisites

* Complete Lessons 01–08
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* What is an Index?
* CREATE INDEX
* DROP INDEX
* Unique Index
* Composite Index
* EXPLAIN
* EXPLAIN ANALYZE

## Learning Outcomes

After completing this lesson, I will be able to:

* Understand how indexes improve query performance
* Create and remove indexes
* Analyze query execution plans
* Choose appropriate columns for indexing
