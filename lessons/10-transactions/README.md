# 10 — Transactions

## Objective

Learn how to manage database transactions to ensure data consistency and reliability in PostgreSQL.

## Prerequisites

* Complete Lessons 01–09
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* BEGIN
* COMMIT
* ROLLBACK
* SAVEPOINT
* Transaction Properties (ACID)
* Isolation Levels

## Learning Outcomes

After completing this lesson, I will be able to:

* Execute multiple SQL statements as a single transaction
* Commit successful changes
* Roll back failed operations
* Use savepoints within a transaction
* Understand the ACID properties of database transactions
