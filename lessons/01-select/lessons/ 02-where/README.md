# 02 — WHERE

## Objective

Learn how to filter data using the `WHERE` clause in PostgreSQL.

## Prerequisites

* Complete Lesson 01
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* Comparison operators (`=`, `!=`, `>`, `<`, `>=`, `<=`)
* Logical operators (`AND`, `OR`, `NOT`)
* `BETWEEN`
* `IN`
* `LIKE`
* `IS NULL`

## Learning Outcomes

After completing this lesson, I will be able to:

* Filter records based on conditions
* Combine multiple conditions
* Search for text patterns
* Check for missing values
* Write readable filtering queries
