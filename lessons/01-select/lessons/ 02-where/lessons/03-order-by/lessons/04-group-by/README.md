# 04 — GROUP BY

## Objective

Learn how to group data and calculate summary statistics using aggregate functions in PostgreSQL.

## Prerequisites

* Complete Lesson 01 (SELECT)
* Complete Lesson 02 (WHERE)
* Complete Lesson 03 (ORDER BY)
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* COUNT()
* SUM()
* AVG()
* MIN()
* MAX()
* GROUP BY
* HAVING
* GROUP BY with ORDER BY

## Learning Outcomes

After completing this lesson, I will be able to:

* Group records by one or more columns
* Calculate summary statistics
* Filter grouped results using `HAVING`
* Produce simple business reports
