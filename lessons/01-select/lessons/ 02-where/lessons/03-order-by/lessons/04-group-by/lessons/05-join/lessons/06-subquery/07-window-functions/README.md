# 07 — Window Functions

## Objective

Learn how to perform advanced analytical queries using Window Functions in PostgreSQL.

## Prerequisites

* Complete Lessons 01–06
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* OVER()
* ROW_NUMBER()
* RANK()
* DENSE_RANK()
* LAG()
* LEAD()
* PARTITION BY
* ORDER BY in Window Functions

## Learning Outcomes

After completing this lesson, I will be able to:

* Rank rows without grouping data
* Compare values between consecutive rows
* Partition data into logical groups
* Build analytical reports using window functions
