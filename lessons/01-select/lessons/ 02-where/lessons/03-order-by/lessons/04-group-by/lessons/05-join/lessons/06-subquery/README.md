# 06 — Subquery

## Objective

Learn how to write subqueries to solve complex SQL problems in PostgreSQL.

## Prerequisites

* Complete Lessons 01–05
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* Scalar Subqueries
* Subqueries in `WHERE`
* Subqueries in `FROM`
* Correlated Subqueries
* `EXISTS`
* `IN`

## Learning Outcomes

After completing this lesson, I will be able to:

* Use subqueries to retrieve intermediate results
* Compare values against aggregated data
* Filter records using `IN` and `EXISTS`
* Build more advanced business queries
