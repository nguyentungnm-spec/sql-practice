# 05 — JOIN

## Objective

Learn how to combine data from multiple related tables using SQL JOIN operations.

## Prerequisites

* Complete Lessons 01–04
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* FULL OUTER JOIN
* Multiple JOINs
* Table Aliases

## Learning Outcomes

After completing this lesson, I will be able to:

* Combine data from multiple tables
* Understand relationships between tables
* Write readable JOIN queries using aliases
* Build simple business reports from relational data
