# 01 — SELECT

## Objective

Learn how to retrieve data from a PostgreSQL database using the `SELECT` statement.

## Prerequisites

* PostgreSQL installed
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* SELECT all columns
* SELECT specific columns
* Column aliases
* DISTINCT
* LIMIT

## Learning Outcomes

After completing this lesson, I will be able to:

* Retrieve data from a table
* Select only required columns
* Rename columns using aliases
* Remove duplicate values with `DISTINCT`
* Limit the number of returned rows
