# Notes

## What I Learned

### SELECT *

Returns every column from a table.

Useful for exploring data, but in real applications it is better to retrieve only the columns that are needed.

---

### Selecting Specific Columns

Selecting only required columns improves readability and may reduce the amount of data transferred.

---

### AS

The `AS` keyword creates a temporary column name (alias).

It makes query results easier to understand.

---

### DISTINCT

Removes duplicate values from the result set.

---

### LIMIT

Returns only the first *N* rows.

Useful when working with large tables.
