# 03 — ORDER BY

## Objective

Learn how to sort query results using the `ORDER BY` clause in PostgreSQL.

## Prerequisites

* Complete Lesson 01 (SELECT)
* Complete Lesson 02 (WHERE)
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* Ascending order (`ASC`)
* Descending order (`DESC`)
* Sorting by multiple columns
* Combining `WHERE` and `ORDER BY`
* Sorting with `LIMIT`

## Learning Outcomes

After completing this lesson, I will be able to:

* Sort records in ascending and descending order
* Sort by multiple columns
* Filter and sort data in a single query
* Retrieve the top or bottom records efficiently
