# 08 — Common Table Expressions (CTE)

## Objective

Learn how to simplify complex SQL queries using Common Table Expressions (CTEs) in PostgreSQL.

## Prerequisites

* Complete Lessons 01–07
* Database created from `database/schema.sql`
* Sample data inserted from `database/seed.sql`

## Topics Covered

* Basic CTE
* Multiple CTEs
* CTE with Aggregate Functions
* CTE with JOIN
* Recursive CTE
* Replacing Subqueries with CTEs

## Learning Outcomes

After completing this lesson, I will be able to:

* Write cleaner and more readable SQL
* Break complex queries into logical steps
* Replace nested subqueries with CTEs
* Use recursive CTEs for hierarchical data
